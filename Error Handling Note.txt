Error Handling Note:

If you encounter the error “Unable to complete action. There was a problem connecting to the data source ‘supply_chain_data’ (Error Code: 88A6ADA0). File not found.”, it means the dataset file is missing. Please download the supply_chain_data.csv file from the provided Drive link and upload it into Tableau. Edit the data source connection to point to the correct file location. Once updated, the Supply Chain Management Dashboard will load successfully.
